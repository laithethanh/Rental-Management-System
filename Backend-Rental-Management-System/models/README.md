# 📂 models/

Thư mục `models` định nghĩa cấu trúc dữ liệu tương ứng với bảng trong database.

## Công dụng
- Mỗi file đại diện cho một bảng (hoặc collection nếu dùng MongoDB)
- Định nghĩa schema & kiểu dữ liệu
- Dùng bởi services để truy xuất DB

## Ví dụ file
- `User.js`
- `Rental.js`
- `Vehicle.js`
- `Payment.js`
